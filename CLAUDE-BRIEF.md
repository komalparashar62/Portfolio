# Brief for Claude

This is Komal Parashar's independent portfolio. Her primary positioning is Product Designer, supported by her current Product Manager experience.

Keep the design expertise prominent. PM knowledge should demonstrate guidance on problem definition, requirements, MVP scope, prioritisation, stakeholder alignment and delivery.

The existing website design uses warm ivory, deep plum and an orange accent, large typography, selective italic serif and original CSS interface artwork. Keep it responsive and accessible.

Do not invent case studies, clients, testimonials, achievements, metrics, years of design experience or a portrait. Do not add work samples until Komal requests them.

The enquiry flow is essential:
1. Visitor selects one or more queries.
2. Submit queries advances to personal details.
3. Ask for a name and a choice of phone OR email. Require only the selected contact method.
4. Final Send enquiry saves the record to Neon Postgres.
5. Confirm success only after the backend accepts the enquiry.
6. Preserve details after errors and query selections when navigating back.

Use CONTENT.md for text and README.md for deployment. This is standalone Next.js intended for Vercel. Do not add Cloudflare, Vinext or host-specific project files.
